Overview

LUMI

A research prototype that reads medical images and reports and explains what it found. It is built for a final-year project on pediatric healthcare decision support, and it supports clinicians rather than replacing them.

Not for clinical use. The skin model has not been clinically validated and has not been shown to be reliable for children.

The skin model and its data

Model
Loading…

It was trained on PAD-UFES-20, a public dataset of 2,298 smartphone skin photos from one program in Brazil (licence CC BY 4.0, Mendeley Data, doi:10.17632/zr7vgbcyr2.1).

The model's score is the average over six classes and is measured on a small held-out set. It is not a clinical validation. The model card in docs/MODEL_CARD_skin_pad_ufes20.md has the full per-class results.

Limitations you should know

  • Not clinically validated. No clinician has reviewed its results, and it is not a medical device.
  • Not validated for children. Almost all patients in the training data are adults. Only 39 of the 2,298 photos come from patients under 18, and all of those show benign nevus. There is no pediatric data for the other five classes.
  • Six classes only. Any photo, including one of another condition or of something that is not skin, is still assigned to one of the six.
  • Limited accuracy. It is wrong on roughly one photo in three, and it confuses several classes. Only 11 melanoma photos were in the test set, so melanoma performance is essentially unknown.
  • Scores are not probabilities of being right. They are the model's own relative scores across its six classes. A high score can still be wrong.
  • Small, single-source data. Other phones, lighting, skin tones, body sites and populations were not tested.
  • Lab reports: accuracy was measured only on a few clean, computer-drawn synthetic reports. It has not been tested on real or photographed reports, and extracted values must be checked against the original.

These figures describe the current dataset and trained model. See the model card for the exact run they belong to.

About the attention map

The attention map (Grad-CAM) colours the parts of a photo that most raised the model's score for the class it chose. Warmer colours mean more influence.

  • It shows what influenced the model, not what is medically important.
  • It is coarse: the model looks at an 8 by 8 grid, so the map shows broad areas, not outlines.
  • A map that looks sensible does not show the prediction is right, and an odd one does not show it is wrong.
  • It explains only the top-scoring class and is not a diagnosis or proof of correctness.

Privacy and security

  • Uploaded files are analysed in memory on the computer running LUMI and are not saved by LUMI. Server logs hold no file names, file contents, report text or predictions.
  • The API needs a key, limits how fast it can be used, and checks every file's type, size and readability.
  • This page loads nothing from other websites, and your key is held only in this browser tab.
